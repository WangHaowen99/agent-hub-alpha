# Builder 首批只读接入

在原 Hub 登录后查看 Intent GATE 的支持状态、构建前置和已有产物的版本来源。新增入口默认关闭，不启动构建、注册、评测、优化或生产激活。

本增量基于 W02/W05 集成候选 #30 的 `41a36755563ebeb442f2d93050c1d3430d510e80`，保留其 WorkSwarm 插件、React Flow、Graph.Rev、BusBindings、原调度器和持久化失败语义。#30 尚未合入 main，因此本增量也不能宣称主线或共享部署已接入。

## 页面和开关

- H01：按 [查询接线说明](docs/builder-h01.md) 配置原 Host、通道凭据、独立签名密钥及当前用户映射。`BUILDER_HUB_ENABLED` 未设置时不注册查询路由，也不显示 Builder 导航。
- 启用后，原页面上已登录用户可见 **Builder** 链接；入口为 `/ui/builder`，保留部署的 `PublicURL` 前缀。实际权限由服务端和原 Host 复核，页面链接不是授权。
- H02：按 [产物交接说明](docs/builder-h02.md) 另行启用产物展示。单独配置产物不自动启用 H01 页面；其 API 仍有独立允许用户检查。
- 关闭两个开关并重启可回退。保留既有任务、版本和证据，不需要数据库迁移。

Demo 登录不代表企业身份。浏览器不能提交 principal、scope、上游地址、证明头或任意构建正文；响应前重新核对当前权限。查询失败不触发重试、构建或新任务。

## 验证

在本目录使用 Go 1.25.0 和原锁定依赖：

```sh
go test -mod=readonly -race -count=1 ./...
go vet -mod=readonly ./...
```

测试覆盖原登录、跨语言签名向量、撤权、错绑/冲突版本、默认关闭及原页面导航。局部替身测试不认证真实 RDC、远端包字节、生产身份或完整业务链。当前候选的实际验证、未运行项与残余风险以 PR 报告为准；此前本地参考分支的原生报告不能当作当前候选重新部署的证据。
